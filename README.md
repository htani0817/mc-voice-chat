# mc-voice-chat

近くにいるプレイヤーとだけ話せる、NeoForge 26.2 のボイスチャット Mod です。声の届く範囲を 5・10・20・30 ブロックの 4 段階で切り替えられます。離れた相手とは、**通話**と**パーティーVC**で話せます。

- 対象: Minecraft 26.2 / NeoForge 26.2.0.88 以降
- 入れる場所: **サーバーと、話す人それぞれのクライアントの両方**
- 追加のポート開放は要りません（声は Minecraft の接続に相乗りします）
- Mod を入れていない人もサーバーに入れます（声が聞こえないだけです）
- Simple Voice Chat とは別の Mod です（名前も Mod の ID もぶつかりません）

## 導入

1. [Releases](https://github.com/htani0817/mc-voice-chat/releases/latest) から `mc-voice-chat-<版>+mc26.2-neoforge.jar` をダウンロードします
2. サーバーの `mods/` に置いて、サーバーを再起動します
3. 話す人のクライアントの `mods/` にも置きます
4. ゲームの中で `V` を押し、設定画面の「マイクテスト」で自分の声が返ってくるかを確かめます

サーバーとクライアントは、同じ版にそろえてください。版が違うと「版が合わない」と出て、声のやり取りをしません。

## 声の届く範囲

| 範囲 | 距離 |
| --- | --- |
| whisper | 5 ブロック |
| normal（既定） | 10 ブロック |
| shout | 20 ブロック |
| supershout | 30 ブロック |

範囲は話す人が選びます。サーバーは「話した人の範囲の内側で、同じディメンションにいる人」にだけ声を送ります。聞く側では、1 ブロック以内はそのままの大きさで、範囲の端で聞こえなくなるまで小さくなります。話している人のいる向きに合わせて、左右にも振ります。範囲の距離は固定で、サーバーの設定では変えられません。

## キー

すべて「設定 → 操作設定 → キー割り当て」の「ボイスチャット」から変えられます。

| 操作 | 既定のキー |
| --- | --- |
| 声の範囲を切り替え（whisper → normal → shout → supershout → whisper） | `@`（JIS 配列。US 配列では `[`） |
| ミュートの切り替え | `M` |
| キーを押して話す（プッシュトゥトーク） | `Caps Lock` |
| ボイスチャットの設定 | `V` |
| 着信に出る／通話を切る | 割り当てなし |

範囲を切り替えたときとミュートを切り替えたときは、画面の中央下に知らせが出ます。

## 通話

サーバーにいるプレイヤー 1 人を呼び出して、電話のように話せます。通話中は、**どのディメンションにいても、どれだけ離れていても**相手に声が届きます。

1. `V` →「通話」タブで相手を選び、「発信」を押します
2. 相手にはベルが鳴り、チャットと画面の右端に着信が出ます。相手は「出る」か「拒否」を選びます（着信中に `V` を押すと「通話」タブが開きます）
3. どちらかが「切る」を押すと、通話が終わります

- 通話は 1 人 1 本です。通話中・呼び出し中の人にはかけられません
- 30 秒応答がなければ取り消します（相手には「不在着信」と出ます）
- 声はふだんの話し方（音声検知かキーを押して話す）で送るので、近くの人にもこれまでどおり聞こえます
- 通話の声は距離で小さくならず、左右にも振りません
- 通話中は、2 人の名前の上に緑で「電話中」が出ます。画面の右端中央には、相手と通話時間が出ます
- 「着信に出る／通話を切る」キーを割り当てると、着信中は押すだけで出られ、発信中・通話中は押すと切れます

## パーティーVC

名前を付けた部屋を作り、入っている人どうしで、ディメンションも距離も問わずに話せます。

- `V` →「パーティー」タブで、パーティー名とパスワード（空欄ならパスワードなし）を入れて「作成して参加」を押します
- 一覧の「参加」で入ります。パスワード付きのパーティーは、パスワードを聞かれます
- 入れるパーティーは 1 人 1 つです。別のパーティーに入ると、前のパーティーから抜けます
- **パーティーへは、キーを押して話す（既定 `Caps Lock`）を押している間だけ声が届きます。** 話し方が音声検知でも同じです
- 入っている間は、画面の右端中央にパーティー名と入っている人（話している人は点が緑）が出ます。名前の上にも水色でパーティー名が出ます

| 操作 | できる人 |
| --- | --- |
| 作成・参加・抜ける | 誰でも |
| 名前を変える・パスワードを変える（空欄で外す） | 作った人 |
| 削除（入っていた人は全員外れる） | 作った人 |

- パーティーはサーバーのメモリーにだけ持ちます。**サーバーを止めるか再起動すると、全部消えます**
- 作った人が抜けても、誰もいなくなっても、パーティーは消えません
- パーティー名は 1〜24 文字で、同じ名前（大文字と小文字の違いだけのものも含む）は作れません。パスワードは 32 文字までです

## 画面端のマイク

既定では左下に、ドット絵のマイクと今の範囲（例 `normal 10`）が出ます。位置は 4 隅から選べ、F1 で HUD を隠すと一緒に消えます。

| 状態 | 見た目 |
| --- | --- |
| 待機中 | 灰色 |
| 声を送っている | 緑 |
| ミュート中 | 灰色に赤い斜線 |
| サーバーが非対応（Mod が入っていない） | 暗い灰色 |

## 設定画面

`V` キーか、Mod 一覧の「mc-voice-chat → 設定」から開きます。開いているあいだもゲームは止まりません。タブは全般・プレイヤー・通話・パーティーの 4 つです。

| 項目（全般タブ） | 内容 |
| --- | --- |
| 話し方 | 音声検知（既定）／キーを押して話す |
| ミュート | マイクのミュート |
| 検知しきい値 | 音声検知のとき、この大きさを超えたら送り始める。既定 -40 dB |
| 声の範囲 | 4 段階から選ぶ |
| マイク入力 | いまのマイクの大きさを横棒で出す |
| マイクテスト | 自分の声を自分に返す（サーバーには送らない） |
| マイク音量・受信音量 | 0〜200%。Minecraft 本体の音量設定とは別 |
| マイク・スピーカー | 使う機器。「既定」は OS の既定の機器 |
| アイコン位置・範囲名の表示 | 画面端のマイクの出し方 |

プレイヤータブでは、1 人ずつ音量（0〜200%）とミュートを変えられます。設定は `config/mc_voice_chat/client.json` に保存されます。

## 仕組み

```text
マイク → 録音（20ms ごと）→ 音声検知 or キー → Opus に圧縮（24kbps）
  → サーバー（届け先を選ぶ）
  → 聞く人の再生（60ms ためて順番をそろえる → 展開 → 大きさを付けて混ぜる）→ スピーカー
```

| 声の届け先 | 届くとき | 聞こえ方 |
| --- | --- | --- |
| 範囲の内側で同じディメンションにいる人 | ふだんの話し方で話しているとき | 距離と向きで大きさと左右が変わる |
| 通話の相手（応答したあとだけ） | ふだんの話し方で話しているとき | そのままの大きさ |
| 同じパーティーの人 | キーを押して話すを押しているとき | そのままの大きさ |

同じ人に複数の道で届くときは、通話 > パーティー > 近く の順で 1 回だけ送ります。Opus の圧縮には純 Java の Concentus を使い、jar に同梱しています。ネイティブのライブラリは要りません。

## 使う前に

- Windows では「設定 → プライバシー → マイク」で、デスクトップアプリのマイクを許可してください。許可していないとマイクを開けず、設定画面に赤字で出ます
- 日本語の機器名が化けて表示されることがあります。化けていても、選べば使えます
- `Caps Lock` で話すと、押すたびに大文字入力が切り替わります。気になるときはキー割り当てで変えてください
- 話し方が「キーを押して話す」のときは、キーが 1 つなので、押すと近くの人・通話の相手・パーティーの全員に届きます
- パーティーのパスワードは、入力欄で伏せ字にならず、サーバーは暗号化せずに覚えています。ほかで使っているパスワードは使わないでください
- 名前の上の表示は、バニラで名前が見える距離と条件（スニーク中は見えにくいなど）に従います

## ビルド

```bash
./gradlew build      # Windows は gradlew.bat build。単体テスト込み
```

- できた jar は `dist/` にコピーされます。ビルド出力は `~/.gradle/project-builds/mc-voice-chat/` に置きます（場所を変えるときは `-PmcBuildRoot=<パス>`）
- 開発用の起動:

  ```bash
  ./gradlew runServer                                   # server.properties で online-mode=false にしておく
  ./gradlew runClient -PvcUser=Alice -PvcJoin=localhost  # 起動したらそのまま localhost に入る
  ./gradlew runClient -PvcUser=Bob -PvcJoin=localhost    # 2 人目
  ```
